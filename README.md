# عيد ميلاد سعيد يا بسمة! 🎂

موقع احتفالي بمناسبة عيد ميلاد بسمة الـ ١٨ — مبني بـ Next.js.

## التشغيل

```bash
npm install
npm run dev
```

افتحي [http://localhost:3000](http://localhost:3000)

## كلمة السر

تاريخ الميلاد: **٢٥ / ٠٥ / ٢٠٠٨**

أشكال مقبولة: `25052008` أو `25/05/2008` أو `25-05-2008`

## المميزات

- واجهة عربية كاملة (RTL)
- صفحة كلمة سر بتاريخ الميلاد
- رسائل تهنئة وتحفيز للثانوية العامة وحلم الطب
- نجوم سرية تفاعلية
- تأثيرات confetti وقلوب متحركة
